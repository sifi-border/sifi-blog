# はじめに

:::note
この記事は[同期 Advent Calendar 2026](https://adventar.org/calendars/13080)
2日目の記事となっています。
:::

ひと月ほど前に AWS の知識がほぼ皆無の状態からAWS SAAに合格できたので、
実践した勉強法を簡単に紹介していきます。

また既存の攻略記事の多くは試験自体の対策に終始しており、
試験会場で実際にどのような段階を踏んで受験に至るかに焦点を当てた
記事は少ないように感じるので、その点も少し述べたいと思います。

## AWS SAA とは

Claudeによる説明です。

> AWS認定ソリューションアーキテクト – アソシエイト (SAA-C03) は、AWS上でのシステム設計の知識を問う中級レベルの資格です。
65問・130分の選択式で、テストセンターかオンライン（自宅）で受験できます。

合格ラインは720/1000で、自分は760でした(危ない)。


# やったこと

1. AWSの基本的な概念やサービスの概要を把握

   - 全てが新しい知識だったので、紙のノートにメモを取りながら進めた。
   - 参考書を読むよりPing-tのようなクイズ形式が効果的だった。能動的でないと頭から抜けていくので。

2. 本番形式の問題を解く

   - 全体をざっくりさらったら模擬試験で実戦的な問題に触れて分量や粒度を把握。
   - 時間を計って通して解くのではなく、一問ずつ解答を確認しながら進め、初見の概念を都度理解しながら進めた。

3. 理解が怪しい分野やサービスの知識を補完

   - 演習で浮き彫りになった弱点分野を参考書などで重点的に補完。

4. 2, 3を時間の許す限り繰り返す。

ハンズオンはEC2,S3などの主要サービスしか実施しませんでした。
一回でも触ると記憶に残りやすいので、可能な限りやるとよいと思います。
言うは易しですが...

準備に費やした期間は3か月程度です。

# 教材

## オンライン教材

- [Ping-t](https://ping-t.com/)

クラウドプラクティショナーで各サービスの概要を把握した。
教材を読む→その分野の演習問題を解く という流れでかなり定着した。
AWSについて本当に何も知らない人間への入り口としてかなりおススメできる。

SAAが有料になってしまったが、CLF(クラウドプラクティショナー)は無料。

:::important
割と本質情報なのですが、
他の口コミや合格体験記を読むと、実はこのサイトだけで十分っぽいです。
:::

- [Udemyの模擬試験](https://www.udemy.com/course/saa-c03-2024aws/)

4回分ほど解いた。

出題内容が本番よりもマニアックめ。
自分は一回も7割を越えられなかった。

- [AWS Black Belt](https://aws.amazon.com/jp/events/aws-event-resource/archive/)

公式が提供している資料集。スライドなので公式ドキュメントよりもカジュアルに追える。
問題演習や参考書を読んでいて不明瞭な箇所があった際に参照していた。

- Claude

AWS Black Beltで扱っていない内容や、
模擬試験で出た不明な点はClaudeに聞いていた。

専用のプロジェクトを用意し、以下のプロンプトを置いていた。

> 適宜AWSの公式ドキュメントを参照し、最新の情報であるかどうかを確認してください。
また、目先の試験突破ではなく、業務で活用できる体系的な知識の獲得を補助してください。
> 
> クイズ形式で確認を促すのも有効かもです。

解説が詳しすぎて取捨選択するのが手間だった一方、
気になる点の追及や図示など便利な側面もあった。

また、些細な質問でもクイズが出題され、放置すると「別スレッドのクイズが未回答です」
みたいなことを言われて厳しかった。
ただ理解を深めるうえで有用ではあったと思う。

音声入力を用いることで、タイプするのと比較してより能動的に取り組めたように思う。

## 参考書

あくまで主観に基づくレビューであることに留意してください。

概要を把握した後に補完するように読んでいた。

# 受験までの流れ

## 予約(8月)

[AWS Certification（Pearson VUE）](https://home.pearsonvue.com/aws)から予約。

市内のテストセンターを調べると、数か所しかなくて驚いた。
静岡市に住んでいるのが良くなさそう。

駅近くに1件あった会場のカレンダーを確認すると、二か月先まで埋まっており横転。

AWSってそんな人気なのか...となっていたが、後述の通りAWS以外の試験も併催されているため
席を奪い合っていると思われる。

とりあえず空いている日から適当に予約。平日しか空いておらず、会社に有休を申請した。

:::note
キャンセルは受験の24時間前まで可能。
:::

## 受験前日(10/29)

退勤後、一夜漬けテキストが1/3ほど残っていたので読み進めようと思っていた。

が、翌週に控えているアイドルの対面イベントの計画を練る会議[^1]が生えてしまい終了。

[^1]: 各アイドルに何枚CDを積むかを事前に相談し、当日のタイムスケジュールを組む。
というのは建前で、雑談をしている時間が大半。

解散後に徹夜で詰め込もうとしたが、眠気にあらがえず就寝。

## 受験当日(10/30)

試験開始の1.5hほど前である9:30頃に起床。バスで静岡駅に向かう。
移動中はKindle端末で一夜漬けテキストを流し読みしていた。

15分前くらいに会場に到着。
壁の三方がロッカーで囲まれ、中央にはパイプ椅子が敷き詰められていた。
奥の方で4,5人くらいの職員が忙しなく動いており、役所のような雰囲気を醸し出していた。

受付の人の表情が険しめで、早く着きすぎても嫌な顔をされそうだった。
何の受験ですか？と尋ねられ、AWS以外の受験者も存在することを察した。

注意事項を書いた紙を渡されパイプ椅子で待機。

## 受験直前

職員に呼び出され、注意事項を再度確認し、電子署名を行った。
スマホを含む所持品をすべてロッカーに格納するよう促され、丸裸で別室に向かった。
この際ホワイトボードとペンを渡された。

別室ではTOEICのように座席が仕切られており、各ブースにPCとモニターが備え付けられている感じだった。

モニターには自分の名前と受験する試験が表示されていたが、後続の人のも下部に表示されており、
個人情報…となっていた。

## 受験中


周囲の音が気になる人向けにイヤーマフ（ヘッドホン型の耳栓）が用意されていたが、
自分は普段メガネをかけており、その上から着用すると
こめかみのあたりが圧迫されて厳しかった。

結果イヤーマフを外して受験したが、気になったのはPCのファンの音くらいでそこまで集中に影響はなかった。

嘘です。隣に座っていた外国の方が巡回していた職員に質問をしており、そのやりとりが丸聞こえだった。
（それは答えられません！それも含めてテストだから！）と無声音で返されており無慈悲だ...となっていた。

受験用アプリのUIが若干年季を感じさせ、懐かしい気持ちになっていた。

:::caution
出題された問題の内容に言及してはいけないみたいな規則があり、
具体的な出題内容には触れられません！
:::

## 受験後

PC上でアンケートを記入。

部屋を退出し、ロッカーから荷物を回収して撤退。

微妙な時間だったので20年ぶりくらいに静岡科学館に寄った。平日ということもありガラガラだった。


当日中にメールで受験結果が届き、合格を確認。
